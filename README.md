# 📊 Superstore Sales Analysis Project

## 📌 Project Overview
This project analyzes Superstore sales data using Python to extract meaningful business insights.

---

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 🎯 Objectives
- Analyze sales and profit
- Identify top-performing regions
- Find best and worst products
- Study monthly sales trends
- Generate business insights

---

## 📂 Dataset Features
- Order Date
- Sales
- Profit
- Category
- Sub-Category
- Region
- Customer Segment

---

## 📊 Key Analysis Performed
- Data cleaning and preprocessing
- KPI calculation (Sales, Profit, Profit Margin)
- Regional performance analysis
- Category-wise analysis
- Product-level analysis
- Time series analysis

---

## 🔍 Key Insights
- Technology category generates highest profit
- West region shows strong performance
- Some products are causing losses
- Sales show seasonal patterns across months

---

## 📈 Conclusion
This analysis helps understand business performance and supports data-driven decision making.
